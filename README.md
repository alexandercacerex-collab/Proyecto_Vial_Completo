# Dashboard Dinámico de Planificación y Control – Proyecto Vial

Versión interactiva para Streamlit.

## Funcionalidades dinámicas
- Filtro por rango de meses.
- Filtro por ruta crítica.
- Filtro por grupos de partidas.
- Selección múltiple de partidas.
- Cambio de métrica principal.
- KPIs recalculados en tiempo real.
- Drill-down por partida.
- Gantt dinámico de ruta crítica.
- Curva S dinámica.
- Simulador de excavación en roca fija.
- Heatmap de sensibilidad eficiencia vs. cuadrillas.
- Tabla editable de escenarios.
- Buscador de registros.
- Descarga de datos filtrados.

## Publicación
Subir todos los archivos a GitHub y desplegar en Streamlit con:
- Branch: main
- Main file path: app.py
